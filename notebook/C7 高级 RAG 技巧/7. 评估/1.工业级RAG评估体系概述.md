# 工业级 RAG 评估体系概述

> 面向架构师和技术负责人，10 分钟读完全景。

## 一、从原型验证到生产评估

在 C5 中，我们学习了基于 Bad Case 的验证迭代方法——人工标注几十条典型问题，逐条检查 RAG 系统的输出质量。这种方式在项目原型阶段非常有效，但进入生产环境后，会遇到三个新挑战：

| 维度 | C5 原型验证 | C7.7 生产评估 |
|------|-----------|-------------|
| **规模** | 几十条 Bad Case，人工逐条检查 | 数百到上千条分桶评估集，自动化批量评估 |
| **持续性** | 一次性检查，改完再手动验证 | 每次改动自动跑回归测试，防止改好了 A 却破坏了 B |
| **可归因性** | 整体打分（"这条答案不好"） | 分层定位（"检索召回不足"还是"生成幻觉"） |

生产评估不是要取代原型验证——Bad Case 分析永远是发现问题的第一步。生产评估是在此基础上，构建**可规模化、可自动化、可归因**的评估闭环。

## 二、评估体系全景图

一个完整的生产级 RAG 评估体系包含以下环节，形成闭环：

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐
│  分层指标    │────▶│ LLM-as-Judge │────▶│  评估集工程   │
│ (Notebook 2) │     │ (Notebook 3) │     │ (Notebook 4) │
└─────────────┘     └──────────────┘     └──────────────┘
       │                                         │
       ▼                                         ▼
┌─────────────┐     ┌──────────────┐     ┌──────────────┐
│  在线监控    │◀────│  CI/CD 门禁  │◀────│  错误归因    │
│ (Notebook 6) │     │ (Notebook 6) │     │ (Notebook 5) │
└─────────────┘     └──────────────┘     └──────────────┘
```

- **分层指标**：把 RAG 系统拆成检索层和生成层，分别度量
- **LLM-as-Judge**：用大模型替代人工，自动打分
- **评估集工程**：构建可维护的分桶评估数据集
- **错误归因**：低分时定位到具体环节和根因
- **CI/CD 门禁**：每次改动自动跑评估，不达标不合并
- **在线监控**：追踪生产环境中的用户反馈和系统指标

## 三、RAG 三元组（RAG Triad）

RAG 系统的评估围绕三个核心元素——Query（问题）、Context（检索上下文）、Response（回答），两两之间形成三个评估维度：

```
         Query
        ╱     ╲
       ╱       ╲
  Context       Answer
  Relevance     Relevance
     ╱             ╲
    ╱               ╲
Context ──────── Response
       Groundedness
       (Faithfulness)
```

| 维度 | 含义 | 目标阈值 |
|------|------|---------|
| **Context Relevance** | 检索到的上下文和问题是否相关 | ≥ 0.75 |
| **Groundedness / Faithfulness** | 答案是否基于检索到的上下文，而非凭空编造 | ≥ 0.80 |
| **Answer Relevance** | 答案是否回答了用户的问题 | ≥ 0.85 |

三元组是 RAG 评估的**最小完备集**——三个维度缺任何一个，都无法全面判断系统质量。

## 四、2026 工具生态

| 工具 | 类型 | 核心能力 | CI 集成 | 中文支持 | 适合场景 |
|------|------|---------|---------|---------|---------|
| **Ragas** | 开源指标库 | 组件级 RAG 指标最全 | 中 | 好 | 离线评估、快速实验 |
| **DeepEval** | 开源测试框架 | pytest 风格，50+ 指标 | 强 | 好 | CI/CD 集成 |
| **TruLens** | 开源评估框架 | RAG Triad，可编程反馈函数 | 中 | 中 | 实验对比、仪表盘 |
| **LangSmith** | 商业平台 | LangChain 生态，实验管理 | 强 | 好 | LangChain 用户 |
| **Langfuse** | 开源可观测 | 操作级评估，OpenTelemetry | 强 | 好 | 在线监控、生产追踪 |
| **Arize Phoenix** | 开源可观测 | UMAP 嵌入可视化 | 中 | 中 | 调试分析 |

详细对比和选型建议见 [7.工具对比与选型](7.工具对比与选型.md)。
