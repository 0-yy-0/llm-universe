# 问题背景

基础 RAG 已经可以返回答案，但返回的内容不一定可靠。下面的 Notebook 用一个具体问题检查资料、检索和回答，最后说明后面各章分别处理哪类问题。

## 本章内容

- [为什么基础 RAG 还会答错](为什么基础%20RAG%20还会答错.ipynb)：从一个具体问题开始，检查资料是否包含答案、检索是否找到正确内容，以及回答是否忠于资料；其中的决策表进一步区分何时改资料/RAG、微调检索器或微调生成器。这一页用于判断问题，不比较某个改法的效果。

Notebook 中还保存了一条使用 canonical gaussian_mean_estimate 的失败诊断 trace：问题的原文证据在数据包中存在，但 BM25 只取前 4 条 evidence 时没有召回目标公式；固定的教学回答草稿因此只能说明资料不足，事后核对再把根因归到“检索/上下文”。这条 trace 只用于演示 query → 检索 → 回答依据 → 错误归因，不是回答模型输出，也不是统一 benchmark。

读完后可以回到[教程首页](../README.md)，根据自己遇到的问题选择后续内容。想继续动手，可直接运行[分块优化](../2.%20数据处理/分块优化.ipynb)、[向量库和资料属性](../3.%20索引阶段/向量库和资料属性.ipynb)和[改写检索问题](../4.%20检索阶段/改写检索问题.ipynb)；它们分别对应资料、索引和检索三类后续路径。
